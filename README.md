## 🌟 特色功能

### 核心玩法
| 系统 | 说明 |
|------|------|
| **境界修炼** | 练气→筑基→金丹→元婴→化神→炼虚→合体→大乘→渡劫，九大境界逐步突破 |
| **💀 死亡与复活** | 🆕 境界分级死亡：低阶「劫后重生」保命一次，金丹以上死亡进入元神状态；新增 `元神状态` / `自然复活` 指令 |
| **战斗系统** | HP/MP/ATK/暴击/防御 真实计算，支持 PVP（切磋/决斗）和 PVE |
| **宗门系统** | 创建/加入宗门，职位管理，宗门建设与捐献 |
| **世界Boss** | 全服Boss降临，多人合力讨伐，按伤害排名瓜分奖励 |
| **🆕 秘境探索** | 刷装备/功法/稀有材料副本，爆率玩法（25%-40%装备，10%-20%功法） |
| **🌍 世界事件** | 🆕 群内多人协作的随机事件：自动生成并广播，报名截止自动开战、结束自动结算；四档难度（低阶/中阶/高阶/史诗），幸存者全额奖励、阵亡者保留 20% 奖励，阵亡触发死亡机制；掉落稀有炼丹材料与专属装备 |
| **⚗️ 炼丹系统（升级）** | 🆕 丹药分 1-5 星（商店只售 1-2 星），境界与炼丹师称号影响成功率，失败返还 50% 材料，5 星还魂丹可完美复活 |
| **🎖️ 炼丹师 & 委托炼丹** | 🆕 金丹期+成功炼制10次+1万灵石可成为炼丹师（+15% 成功率、自动解锁还魂丹配方）；玩家之间可委托炼丹：发布委托 → 炼丹师接单 → 交付成品领取手续费 |
| **传承系统** | 传承挑战争夺Buff加成，传承排行榜竞技 |

### 🧘 修炼突破
| 指令 | 说明 |
|------|------|
| `闭关` | 开始闭关修炼，离线也可积累修为 |
| `出关` | 结算闭关时间，获取对应修为 |
| `突破信息` | 查看当前境界突破所需修为、成功率、风险 |
| `突破 [丹药名]` | 尝试突破，可服用丹药增加成功率 |

> ⚠️ **突破失败有概率走火入魔**（默认 1%~10%），不同境界后果完全不同：
> - **练气期-筑基期**（境界 0-12）：首次死亡触发「劫后重生」——境界倒退 1 级、保留 70% 修为、状态清空；第二次死亡将彻底陨落（删除角色）
> - **金丹期及以上**（境界 13+）：死亡进入【元神状态】，角色不会被删除，可等待自然复活或使用还魂丹
> - PVP（决斗/切磋）、Boss 战失败**不会**触发真正死亡，仅维持原有惩罚

### 💀 死亡与复活 🆕 v3.5.8
| 指令 | 说明 |
|------|------|
| `元神状态` | 查看元神状态：已流逝时间、修为流失比例、自然复活倒计时 |
| `自然复活` | 元神状态等待期满（默认 24 小时）后复活，永久损失 5% 修为 |
| `使用还魂丹` | 🆕 5 星稀有丹药，立即完美复活（修为无损）；也可用 `服用丹药 还魂丹` |

> **元神状态规则**
> - 进入时修为锁定为死亡前的 **50%**，此后每小时流失 1%（可配置）
> - 超时未复活（默认 24×4 小时）时修为归零并强制复活
> - 元神状态下**无法修炼与战斗**（闭关、突破、秘境探索、加入世界事件、决斗、切磋、Boss、宗门事务等一律禁止）
> - 仍可使用：`我的信息`、`签到`、`银行`、背包/商店浏览、排行榜等只读指令
>
> **配置项（`config/death_config.json`）**
>
> | 配置项 | 默认值 | 说明 |
> |--------|--------|------|
> | `soul_revival_hours` | 24 | 元神状态自然复活所需小时数 |
> | `soul_exp_loss_rate` | 0.05 | 自然复活永久损失的修为比例 |
> | `rebirth_exp_keep_rate` | 0.7 | 「劫后重生」保留的修为比例 |
> | `soul_exp_decay_per_hour` | 0.01 | 元神状态每小时流失的修为比例 |

### 🎒 装备丹药
| 指令 | 说明 |
|------|------|
| `我的装备` | 显示已装备的武器/防具/心法/功法及属性 |
| `修仙装备 <名>` | 从储物戒装备到身上；普通功法最多同时装备3个（原 `装备`，为避免与钓鱼等插件冲突而更名） |
| `卸下 <名>` | 卸下装备放回储物戒（别名 `修仙卸下`） |
| `丹药背包` | 查看拥有的丹药及效果 |
| `服用丹药 <名> [数量]` | 使用丹药获得增益，支持批量（如 `服用丹药 凝气丹 10`） |
| `一键服用` | 🆕 一键服用背包中所有可服丹药（自动遵守属性上限/效果不叠加等限制） |

> 功法通过百宝阁购买或秘境掉落获得，存入储物戒后使用 `修仙装备 <功法名>` 装备，最多同时装备3个（细分类型带「心法」的功法主修 1 个，提供修为倍率加成）。
> 功法提供法伤、物伤、防御、精神力、灵气/气血容量或寿命等被动属性，装备后会计入 `我的信息`、战斗和战力计算。
> 💡 指令更名：`装备` 与钓鱼类插件冲突，本插件统一使用 `修仙装备`（`装备物品` 亦可）。

**宗门每日任务（每日 00:00 重置，自动检测完成）**

| 任务 | 条件 | 奖励 |
|------|------|------|
| 💰 捐献灵石 | 单次捐献 ≥1000 灵石 | +50 贡献度 |
| 🌍 参与世界事件 | 参与世界事件并生还 | +30 贡献度 |
| 🌾 收获灵田 | 收获一次灵田 | +20 贡献度 |
| 🌀 探索秘境 | 完成一次秘境探索 | +40 贡献度 |

**宗门功法共享**

- 宗主/长老可 `捐献功法 <功法名>` 把功法放进宗门功法库（**功法仍保留在自己身上**，其他人只是借用）
- 成员可 `借用功法 <功法名>`，借期 7 天，最多同时借 2 个，借到后自动装备
- 到期自动归还：在 `我的信息` 或 `出关` 时检测并卸下

> ⚠️ **关于「丹房」等字段**：`sects` 表中存在 `sect_materials`（宗门资材）、`elixir_room_level`（丹房等级）、
> `sect_fairyland`（洞天福地等级）、`mainbuff`/`secbuff`（主修/辅修功法）等字段，
> 它们是**数据结构预留位**，仅「宗门资材」会随宗门建设任务增长并在 `我的宗门` 中展示，
> **丹房/宗门洞天暂未开放实际玩法**。

#### 💼 委托炼丹（批次3）

玩家之间交易炼丹服务：**委托人出材料与手续费，炼丹师负责炼制并交付成品**。

| 阶段 | 指令 | 说明 |
|------|------|------|
| 发布 | `委托炼丹 <配方ID> [数量] [手续费] [@炼丹师]` | 材料（含配方中的灵石消耗）与手续费从委托人身上扣除并托管锁定；不指定炼丹师则发布到公开委托板 |
| 查看 | `委托列表` / `我的委托` | 公开委托板按手续费从高到低排序；`我的委托` 展示发布与接单的委托 |

> 约束：未接单委托上限 `commission_max_pending`（默认 5）、同时进行中的委托上限 `commission_max_active`（默认 3）、单笔数量上限 `commission_max_quantity`（默认 99）。

### 历史版本：v3.5.6 - 宗门每日任务跨天结算修复 🔧

**🐛 问题修复：**
- 修复宗门成员「完成探索」报 `UNIQUE constraint failed: sect_daily_tasks.user_id`：
  `sect_daily_tasks` 建表时误把 `user_id` 设为单主键，而每日任务需要按
  `(user_id, task_date)` 每天写入一行 —— 玩家当天能建记录，**次日**再建就主键冲突，
  导致秘境探索 / 世界事件 / 收获灵田 / 宗门捐献的每日任务结算全部失败。
  现改为 `(user_id, task_date)` 复合主键，并新增 **v31 数据库迁移**自动重建老库
- 任务标记改为原子更新（`rowcount` 判定首次完成），避免重复触发时重复发放贡献度
- 命中旧表结构时运行时会自动重建兜底（无需手动删库）
- 顺带修复由此引发的连锁故障：`购买` 等指令报 `cannot start a transaction within a transaction`
  （失败的写入语句残留事务未回滚，导致后续所有 `BEGIN IMMEDIATE` 指令持续失败）。
  现统一走自愈事务入口 `begin_immediate()`：检测到残留事务自动回滚并重试
- 插件启动时新增**表结构自检**：即使版本号已是最新也会校验并修复该表结构
- **每日任务结算静默降级**：结算异常只记日志并跳过奖励，不再拖垮「收获」「完成探索」等主指令

**📦 数据库变更：**
- 新增 v31 迁移：`sect_daily_tasks` 重建为 `(user_id, task_date)` 复合主键，
  保留原有任务进度数据，插件启动时自动执行

一款为 AstrBot 设计的、功能丰富的放置类修仙游戏插件。让你在聊天群中体验从凡人到大能的修行之路，工作摸鱼、畅聊吹水的同时亦可得道飞升！

---

## 🌟 特色功能

### 核心玩法
| 系统 | 说明 |
|------|------|
| **境界修炼** | 练气→筑基→金丹→元婴→化神→炼虚→合体→大乘→渡劫，九大境界逐步突破 |
| **战斗系统** | HP/MP/ATK/暴击/防御 真实计算，支持 PVP（切磋/决斗）和 PVE |
| **宗门系统** | 创建/加入宗门，职位管理，宗门建设与捐献 |
| **世界Boss** | 全服Boss降临，多人合力讨伐，按伤害排名瓜分奖励 |
| **🆕 秘境探索** | 刷装备/功法/稀有材料副本，爆率玩法（25%-40%装备，10%-20%功法） |
| **历练系统** | 日常材料农场，获取炼丹材料+经验灵石，稳定产出 |
| **炼丹系统** | 收集材料炼制丹药，提升修为或增加属性 |
| **传承系统** | 传承挑战争夺Buff加成，传承排行榜竞技 |

### 独有系统
| 系统 | 说明 |
|------|------|
| **🏔️ 洞天福地** | 个人修炼空间，5档洞天可选，持续产出灵石和修为，支持转让换购 |
| **🌾 灵田种植** | 开垦灵田种植灵草，5种灵草不同收益周期 |
| **💕 双修系统** | 与他人双修互增10%修为，1小时冷却 |
| **👁️ 天地灵眼** | 抢占灵眼持续获益，PVP资源争夺玩法 |
| **👨‍🏫 师徒系统** | 高境界玩家收徒传道，获得徒弟修炼收益；低境界玩家拜师，获得灌顶助力 |
| **🤝 组队秘境** | 🆕 2-4人组队探索高难度秘境，队伍平均等级准入，探索时间缩短，掉落加成，3个组队专属副本 |

## 📜 指令大全

### 📖 入门 & 基础
| 指令 | 说明 |
|------|------|
| `我要修仙 [灵修/体修]` | 创建角色，灵修擅法术，体修擅肉身 |
| `我的信息` | 显示境界、修为、战力、装备与已装备功法效果 |
| `签到` | 每日领取灵石(50-200)和修为奖励 |
| `改道号 <名称>` | 修改你的仙道称号 |
| `弃道重修 [确认]` | 删除角色并清空数据，7天内仅可执行一次，需追加”确认” |

### 🧘 修炼突破
| 指令 | 说明 |
|------|------|
| `闭关` | 开始闭关修炼，离线也可积累修为 |
| `出关` | 结算闭关时间，获取对应修为 |
| `突破信息` | 查看当前境界突破所需修为、成功率、风险 |
| `突破 [丹药名]` | 尝试突破，可服用丹药增加成功率 |

### 🎒 装备丹药
| 指令 | 说明 |
|------|------|
| `我的装备` | 显示已装备的武器/防具/心法/功法及属性 |
| `装备 <名>` | 从储物戒装备到身上；普通功法最多同时装备3个 |
| `卸下 <名>` | 卸下装备放回储物戒 |
| `丹药背包` | 查看拥有的丹药及效果 |
| `服用丹药 <名>` | 使用丹药获得增益 |

> 功法通过百宝阁购买后存入储物戒；使用 `装备 <功法名>` 装备，最多同时装备3个。功法提供法伤、物伤、防御、精神力、灵气/气血容量或寿命等被动属性，装备后会计入 `我的信息`、战斗和战力计算。

### 🏪 商店系统
| 指令 | 说明 |
|------|------|

| `器阁` | 装备专卖(武器/防具/饰品) |

### 🏛️ 宗门系统
| 指令 | 说明 |
|------|------|
| `创建宗门 <名>` | 消耗灵石创建宗门 |
| `加入宗门 <名>` | 加入已有宗门 |

**🆕 宗门福利系统：**
- **修炼加成**：根据宗门建设度提供修炼速度加成（5%-30%）
  - 1-5000：初级宗门 +5%
  - 5001-20000：中级宗门 +10%
  - 20001-50000：高级宗门 +15%
  - 50001-100000：顶级宗门 +20%
  - 100001+：超级宗门 +30%
- **功法共享**：高职位成员捐献功法，低职位成员可借用（7天自动归还）
- **宗门秘境**：专属秘境，奖励更丰厚（奖励提升50%）
  - 建设度10000+：解锁"宗门试炼地"（金丹期推荐）
  - 建设度30000+：解锁"宗门秘藏"（元婴期推荐）
  - 建设度60000+：解锁"宗门禁地"（化神期推荐）
- **每日任务**：完成任务获得额外贡献度
  - 捐献灵石（1000灵石，+50贡献度）
  - 完成历练（任意历练，+30贡献度）
  - 种植灵草（收获灵田，+20贡献度）
  - 探索秘境（完成秘境，+40贡献度）

| 指令 | 说明 |
|------|------|
| `秘境列表` | 查看15个主题秘境及奖励 |
| `探索秘境 <ID>` | 进入秘境（30-60分钟） |

**秘境定位：** 刷装备/功法/稀有材料副本，爆率玩法
- **Lv.1 炼气期**（2个）：剑冢遗迹、灵兽巢穴 - 间隔拉大，避免过密
- **Lv.2 筑基期**（2个）：丹师洞府、玄冰洞窟
- **Lv.3 金丹期**（2个）：天火秘境、雷霆试炼地
- **Lv.4 元婴期**（2个）：幽冥血海、星辰殿堂
- **Lv.5 化神-炼虚期**（2个）：九幽黄泉路、上古战场
- **Lv.6 合体-大乘期**（2个）：混沌神殿、万界战场
- **Lv.7 渡劫期**（1个）：九天劫雷场
- **Lv.8 仙境**（2个）：仙道试炼、诸天战场 🆕

**等级限制：**
- 最低等级：必须达到秘境要求境界
- 等级过高警告：超过推荐等级10级，掉落率降低
- 等级过高禁止：超过推荐等级20级，无法进入

**组队机制：**
- **准入规则**：队伍平均等级 ≥ 秘境要求等级
- **探索时间**：2人90%，3人80%，4人70%
- **掉落加成**：2人+20%，3人+35%，4人+50%
- **经验分配**：所有队员获得100%经验（不分摊）
- **传承加成**：低等级队员获得额外经验（队友高10级+30%，高20级+50%）
- **次数限制**：每人每日每个秘境5次（单人和组队共享）

**组队专属秘境：**

| 天道试炼 | 炼虚期(28) | 4人满编 | 神器装备、至尊功法 |

| `逐出师门 <@徒弟>` | 解除师徒关系 |
| `离开师门` | 主动离开师门 |

**师徒系统特色：**
- 🎓 **收徒条件**：元婴期以上，最多收3个徒弟
- 👶 **拜师条件**：金丹期以下，每人只能有1个师父
- 💰 **传道奖励**：徒弟修炼、历练时，师父自动获得8%收益
- ✨ **灌顶功能**：师父每日可传授修为助徒弟快速成长
- 🎁 **出师奖励**：徒弟达到筑基期自动出师，师父获得丰厚奖励（5万灵石+稀有材料）

| 类别 | 示例 | 作用 | 获取方式 |
|------|------|------|------|
| 破境丹 | 筑基丹、凝婴丹、化神丹 | 直接提升指定境界的突破成功率，部分丹药可将总成功率拉满 | 丹阁刷新、秘境稀有掉落 |
| 修为丹 | 炼气丹、玄灵丹、九转灵丹 | 立即增加修为值（200-10万+），全部存入丹药背包可随时服用 | 丹阁、炼丹系统、历练/秘境结算奖励 |
| 功能丹/灵丹 | 修炼加速丹、力量丹、灵智丹、回生丹 | 包含临时修炼倍率、永久属性增减、复活、定魂护盾等特殊效果 | 丹阁稀有刷新、Boss与高阶秘境掉落 |
| 百宝丹药（即时消耗） | 一品气血丹、三品凝神增益丹 | 购买后立即恢复气血/灵气、增减属性或短暂提升突破成功率 | 百宝阁限量出售（无法存入背包） |
| 材料 | 灵草、玄铁、星辰石、天材地宝 | 炼丹配方、悬赏任务、装备升级所需的基础资源 | 历练、秘境、悬赏、世界Boss掉落，灵田收获可持续产出灵草 |
| 法器/功法 | 青锋剑、玄铁甲、焚天诀、他化自在大法 | 装备/心法提供物伤、法伤、防御与修炼倍率等长期加成 | 器阁 / 百宝阁刷新，高级 Boss 亦可掉落稀有法器 |

💡 使用 `物品信息 <名称>` 可随时查询任意上架物品或丹药的详细效果与推荐获取途径。

## ⚙️ 配置说明

插件首次运行后，将在 `data/plugins/astrbot_plugin_monixiuxian2_niko/config/` 目录下自动生成默认配置文件：

| 配置文件 | 作用 |
|---------|------|
| `sect_config.json` | 宗门创建消耗、职位权限、任务奖励 |
| `boss_config.json` | Boss 属性成长曲线、生成间隔 |
| `rift_config.json` | 秘境名称、等级要求、探索时长、奖励池 |
| `alchemy_config.json` | 丹药配方、材料消耗、成功率计算 |

**注意**：修改配置后需重启 AstrBot 生效。
